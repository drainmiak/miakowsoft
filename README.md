# miakowsoft
# miakowsoft — инструкция по запуску

```
создатель линукса сказал что никогда не притронулся бы к вашему компьютеру
не потому что он уважает частную собственность,а потому что ваш компьютер говно
```

## линукс(я дрочу на лiнукс)

```bash
cd miakowsoft
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

## шишвиндовс(виндовс)

```powershell
cd miakowsoft
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
py main.py
```

## тэрмукс

```bash
pkg update
pkg install python
cd miakowsoft
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```
