## линукс(я дрочу на лiнукс)

```bash
cd miakowsoft
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

## шишвиндовс(виндовс)

```powershell
cd miakowsoft
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
py main.py
```
